# SEA Trend Calendar

## 数据来源说明

- 节日、营销节点和气候信息整理自互联网公开资料，以本地数据文件提供。
- 类目、TGI、规模、阶段、价格区间、排名和关联关系均由固定随机种子生成。
- 商品、素材、效果指标及六国热搜词均为虚构演示数据。
- 商品图和素材封面使用通用、无品牌的 AI 示意图。
- 页面中的数值和内容仅用于功能演示，不代表实际市场表现。

## 业务范围说明

- 覆盖东南亚整体及马来西亚、泰国、越南、菲律宾、新加坡和印度尼西亚六个国家。
- 提供节日与气候日历、趋势类目热力图、类目排名、价格区间分布和机会矩阵。
- 提供 Products、Creatives 和 Search 三类实时视图。
- 支持国家、月份、类目和关键词筛选，以及分页、趋势查看、详情预览和深浅主题切换。

## 使用说明

双击 `Start Demo.command`，服务启动后访问：

```text
http://127.0.0.1:5174/
```

也可以在项目目录运行：

```bash
npm ci
npm run dev
```

关闭启动窗口或按 `Control + C` 可停止本地服务。AI 示意图需要联网加载；图片暂不可用时，不影响其他筛选和图表功能。
