# SEA Trend Calendar · Interactive Demo

独立 React + TypeScript + Vite 演示工程。保留日历、气候、图表、筛选、深浅主题和详情交互，不连接原业务系统。

**数据均为非真实业务数据，仅用于交互功能演示。**

## 打开网页

双击 `Start Demo.command`，然后访问 **http://127.0.0.1:5174/**。关闭终端或按 Ctrl+C 会停止服务。

也可以运行：

```bash
npm ci
npm run dev
```

## 数据与媒体边界

- 日历和气候来自互联网公开信息，保留 100 条节日/营销节点及六国 72 条月度气候记录。
- 480 个三级类目由固定随机种子独立生成，不保留原业务类目的名称、数量、分支或顺序。
- 七市场 TGI、规模、阶段、价格段、排名和节日关联全部由固定随机种子生成。
- 600 个商品和 600 条素材的名称、类目、国家、价格、标签及效果指标全部模拟。
- 六国各 100 条热搜词、排名、搜索指数、7 日涨幅和趋势曲线全部由固定随机种子生成。
- 商品图和素材封面通过指定 AI 图像服务生成，仅使用通用无品牌提示词。
- 商品详情、素材详情和 12 秒播放器均为站内交互，不含原商品链接、视频 ID、视频预览地址或签名封面 URL。
- 不连接飞书、Aime、公司 SSO、访问日志、商品 CDN或创意平台。
- TT4B Logo、原商品图、原视频封面和含真实素材的旧截图均不在交付物中。

AI 图像按需联网加载。生成服务未就绪或请求失败时，页面显示英文状态提示，筛选、分页、详情和播放器仍可操作。

## 功能

- 六国与月份联动、两种甘特视图、气候信息卡。
- 三级虚构类目筛选、热力图排序与分页。
- 排名下钻、七市场 TGI 走势、价格段明细与气泡数量滑杆。
- Products / Creatives / Search 三视图切换，各自保留筛选状态。
- 商品/素材独立筛选、商品关键词搜索、50/100/200 条分页。
- 六国 Top 100 热搜词切换、本地关键词筛选、指数条与 7 日趋势。
- AI 商品图灯箱、AI 素材封面、本地播放/暂停/拖动/重播/全屏。
- 深浅主题切换与刷新记忆。

## 构建与验证

```bash
npm test
npm run build
npm run verify:demo
npm run test:e2e
python3 scripts/package-demo.py
```

`verify:demo` 会阻止飞书/Aime 接口、原媒体域名、视频 ID、签名 URL、旧媒体数据文件、原 Logo 和 source map 进入生产产物。

交付文件：

- `artifacts/sea-trend-demo-source.zip`：可编辑源码、测试、文档和启动脚本。
- `artifacts/sea-trend-demo-static.zip`：可部署的静态网站。

静态包内部文件可部署到根目录或子目录，不需要后端、账号、环境变量或数据源权限。不要通过 `file://` 双击打开 `dist/index.html`；本地生产预览使用 `npm run preview`。
